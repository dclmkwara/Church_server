# Quickstart (Non-Technical)

## Step 1: Create the Hierarchy
Add nation, state, region, group, location, and fellowships in order.

## Step 2: Register Workers
Create worker records for staff and volunteers.

## Step 3: Create User Accounts
Create login accounts for workers who need system access.

## Step 4: Enter Data
Record counts, offerings, attendance, and newcomers.

## Step 5: Use Reports
Export reports in CSV/Excel/PDF.
