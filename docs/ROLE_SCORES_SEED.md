# Role Scores Seed Script

This script seeds the 1–9 role score levels for the church hierarchy.

## Run
From the project root:
```
python scripts/seed_role_scores.py
```

## Levels
1. Level 1 — ordinary usher / basic worker at location level.
2. Level 2 — special responsibilities at location level (coordinator, financial secretary, sister welfare, etc.).
3. Level 3 — highest location-level authority (location pastor).
4. Level 4 — group level leadership and key positions.
5. Level 5 — region level leadership and key positions.
6. Level 6 — state level leadership and key positions.
7. Level 7 — national level leadership and key positions.
8. Level 8 — general church admin level leadership.
9. Level 9 — super admin with all system rights.
