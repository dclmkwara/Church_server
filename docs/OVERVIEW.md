# Server Overview (Non-Technical)

This server is the central system for Deeper Christian Life Ministry, Kwara State branch. It stores church data and powers all apps and dashboards.

## Plain Language Summary
- It keeps a **structured map** of all church locations.
- It stores **people records** (workers and users).
- It collects **attendance and offerings**.
- It generates **reports** for leaders.
- It provides **public information** like events and locations.

## What It Does Not Do
- It does not provide a frontend UI by itself.
- It does not send SMS or email by default.
- It does not auto-generate payments; it only records them.

## Typical Use Cases
- Sunday service count submission.
- Weekly offering upload.
- Worker registration and approval.
- Admin report downloads.
